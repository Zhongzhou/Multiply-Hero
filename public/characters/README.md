# Character pictures

Swap any file in this folder and refresh. Keep the filename. The pictures are the poses the game shows today, so it looks the same until you replace one.

Win pictures still hop. Lose pictures still tip over onto the ground.

## Pengy

- `pengy-standing.png` — hero page when Pengy is not selected, and while a question is waiting
- `pengy-laughing.png` — Pengy is selected on the hero page
- `pengy-sticking-out-tongue.png` — Pengy answers correctly
- `pengy-crying.png` — Pengy answers wrong
- `pengy-laughing-and-jumping.png` — Pengy wins the fight
- `pengy-on-the-ground-crying.png` — Pengy loses the fight
